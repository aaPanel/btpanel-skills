2. pgsql 服务信息
   - 使用uri: /plugin?action=a&name=pgsql_manager&s=get_service
   - 响应: `{"data": ["\u5f00\u542f", 1], "status": true}`
   - data字段信息即服务状态

3. 多版本共存的php服务查询
   - 服务名称格式：php-x.x
   - 版本包含:
     - 8.5
     - 8.4
     - 8.3
     - 8.2
     - 8.1
     - 8.0
     - 7.4
     - 7.3
     - 7.2
     - 7.1
     - 7.0
     - 5.5
     - 5.4
     - 5.3
     - 5.2
   > 使用： /plugin?action=get_soft_list&type=-1&query=php&p=1&row=30&force=0
   > 响应性取只其中的 list字段，并且 list中每项的name字段与服务名称完全匹配的才是对应的php服务，每项的格式nginx等服务的格式类似

     2. 各个服务的各种日志的位置
        - nginx 错误日志文件 => /www/server/nginx/logs/error.log
        - apache 错误日志文件 => /www/wwwlogs/error_log
        - redis 日志文件 => /www/server/redis/redis.log
        - pgsql 日志（特殊接口）: /plugin?action=a&name=pgsql_manager&s=get_pgsql_log
        - pgsql 慢日志（特殊接口）: /plugin?action=a&name=pgsql_manager&s=get_slow_pgsql_log
        - memcached 与 pgsql无法使用api接口查询到日志
        - mysql 日志（接口）： /database?action=GetErrorLog
        - mysql 慢日志（接口）： /database?action=GetSlowLogs
